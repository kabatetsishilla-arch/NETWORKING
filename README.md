What is Networking?

Networking is the process of connecting two or more computers or devices so that they can communicate and share information and resources.

For example, computers connected in a school can share files, printers, internet, and other resources.

Types of Computer Networks

The main types are:

PAN – Personal Area Network
Covers a very small area around one person.
Example: connecting a phone to Bluetooth headphones.
LAN – Local Area Network
Covers a small area such as a home, office, school, or computer laboratory.
Example: computers connected in a school lab.
MAN – Metropolitan Area Network
Covers a city or large town.
Example: connecting several offices within a city.
WAN – Wide Area Network
Covers a very large geographical area, such as countries or continents.
Example: the Internet.
WLAN – Wireless Local Area Network
A LAN that uses wireless communication, usually Wi-Fi.
Example: Wi-Fi in a home or university.
Network Layers

Network layers explain how data moves from one device to another.

The most common model taught in networking is the OSI model, which has 7 layers.

Layer	Name	Simple meaning
7	Application	Provides network services to users/apps
6	Presentation	Formats, encrypts and compresses data
5	Session	Starts, manages and ends communication
4	Transport	Ensures data is delivered correctly
3	Network	Finds the path and uses IP addresses
2	Data Link	Transfers data between directly connected devices
1	Physical	Sends bits through cables or wireless signals

Simple example

When you send a WhatsApp message:

Application → Presentation → Session → Transport → Network → Data Link → Physical

The data moves down the layers on your device, travels across the network, and then moves up the layers on the receiver's device.

In short

Networking = connecting devices so they can communicate and share resources.

Network types = PAN, LAN, MAN, WAN and WLAN.

OSI layers = 7 layers that explain how data travels across a network.
